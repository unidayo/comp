# 最短経路問題

アルゴリズム選択、モデル化、負閉路、差分制約（通称「牛ゲー」）を競技中に確認するためのノート。

## 1. アルゴリズム選択

| 条件 | アルゴリズム | 計算量 |
|---|---|---:|
| 重みなし・全辺同一重み | BFS | $O(N+M)$ |
| 辺重みが `0/1` | 0-1 BFS | $O(N+M)$ |
| 全辺重みが非負 | Dijkstra | $O((N+M)\log N)$ |
| 負辺あり | Bellman–Ford | $O(NM)$ |
| DAG | トポロジカル順 DP | $O(N+M)$ |
| 全点対、`N` が小さい | Floyd–Warshall | $O(N^3)$、メモリ $O(N^2)$ |
| 差分制約の充足可能性 | Bellman–Ford / SPFA | Bellman–Ford は $O(NM)$ |

- Dijkstra は負閉路の有無ではなく、負辺がないことが前提。
- DAG なら負辺があってもトポロジカル順 DP でよい。
- SPFA は最悪 $O(NM)$。平均的な速さだけを根拠に使わない。
- 密グラフでは、優先度付きキューを使わない $O(N^2)$ Dijkstra が適する場合がある。
- 負辺があり全点対を求める疎グラフでは Johnson 法も候補。

選択基準は「値が小さいか」ではなく辺重みの性質。例えば重みが `1` と `2` だけでも BFS ではなく Dijkstra、重みが `0` と `1` だけなら Dijkstra でも正しいが 0-1 BFS の方が計算量を落とせる。

ワークスペースの実装：

- `mylib/graph/shortest_path/dijkstra.cpp`
- `mylib/graph/shortest_path/bellman_ford.cpp`
- `mylib/graph/shortest_path/warshall_floyd.cpp`

利用前に、必要な負閉路伝播や `INF` 加算対策が実装されているか確認する。

## 2. モデル化のパターン

### 状態拡張

今後の遷移が「現在の頂点」だけで決まらないなら、必要な情報を状態に含める。

```text
(頂点, チケット使用回数)
(マス, 向き)
(頂点, 訪問済み集合)
(頂点, 時刻 mod 周期)
```

状態数と遷移数が制約内かを先に見積もる。

同じ状態に到達した後の選択肢と追加費用が過去の経路に依存しないことが、状態をまとめられる条件。必要情報を落とすと異なる状況を同じ頂点として扱って誤答になり、逆に不要な履歴まで持つと状態数が破綻する。

### 多始点

全始点の初期距離を `0` にしてキューへ入れる。超始点から各始点へ重み `0` の辺を張ることと同じ。

「いずれかの始点からの最小距離」を 1 回の探索で求める変換であり、始点ごとの距離を区別したい場合には使えない。

### 終点固定

全頂点から固定終点 `t` までの距離は、全辺を反転して `t` から最短路を求める。

反転後の `t -> v` の経路は、元グラフの `v -> t` の経路と辺が逆順に対応し、重みの総和は変わらない。有向グラフで始点ごとに探索する必要をなくせる。

### 頂点コスト

頂点 `v` に入る費用なら、各進入辺 `u -> v` に `cost[v]` を加える。より一般には `v_in -> v_out` に頂点コストを持たせる頂点分割を使う。

### 使用回数制限付きの特殊操作

特殊辺を高々 `K` 回使えるなら `(v,k)` を作り、通常辺は同じ層、特殊辺は `k -> k+1` の層へ張る。`K` が大きい場合は別の構造が必要。

答えが「高々 `K` 回」なら、終点の層 `0..K` の最小値を取る。「ちょうど `K` 回」と混同しない。

## 3. 実装上の要点

### 0-1 BFS

緩和した辺の重みが `0` なら deque の先頭、`1` なら末尾へ追加する。`0/1` 以外の重みを混ぜない。

先頭にある距離を `d` とすると、新候補は `d` または `d+1` だけなので、deque 内を距離の小さい順に保てる。これが priority queue を使わずに済む理由。

### Dijkstra

- priority queue から取り出した `(du,u)` が `du != dist[u]` なら古い候補なので捨てる。
- 目的地が queue に入った時点ではなく、最新距離として取り出された時点なら早期終了できる。
- 経路復元は緩和時に `prev[v] = u`、辺が必要なら辺 ID も保存する。

未確定頂点のうち距離最小の `u` を取り出した後、非負辺を通るどの迂回路も `dist[u]` より短く戻れないため距離を確定できる。負辺が 1 本でもあるとこの確定性が崩れるので、実装が再緩和できそうに見えても前提外。

### Floyd–Warshall

```cpp
for (int k = 0; k < N; ++k)
    for (int i = 0; i < N; ++i)
        for (int j = 0; j < N; ++j)
            if (dist[i][k] != INF && dist[k][j] != INF)
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
```

- `dist[i][i] = 0` で初期化する。
- 多重辺は `dist[u][v] = min(dist[u][v], w)`。
- `k` を最外ループにする。
- 終了後に `dist[v][v] < 0` なら `v` を含む負閉路がある。

`k` 回目の終了時点では、中継点として `0..k` のみを許した最短距離になっている。`k` を内側へ移すとこの DP の依存順序を壊す。

## 4. Bellman–Ford と負閉路

負閉路がなければ、単純な最短経路の辺数は最大 `N-1`。全辺緩和の `N` 回目にも更新される頂点は、始点から到達可能な負閉路の影響を受ける。

`i` 回の全辺緩和が終われば、高々 `i` 本の辺を使う経路の距離は必ず反映される。in-place 更新ではそれより先まで同じ反復中に伝わることもある。閉路を除けば辺数は `N-1` 以下なので、それを越えて改善するには総重みが負の閉路を利用している必要がある。`N` 回目に更新された頂点が負閉路上とは限らず、負閉路から更新が伝わった先の場合もある。

### 目的地への影響

負閉路がグラフ内にあるだけで `s -> t` の距離が $-\infty$ とは限らない。

1. `s` から負閉路へ到達可能。
2. 負閉路から `t` へ到達可能。

の両方が必要。

判定方法：

- `N` 回目に更新された頂点から探索し、到達頂点へ負閉路の影響を伝播する。
- または `s` から到達可能、かつ反転グラフで `t` から到達可能な部分だけに絞る。

最大得点を辺重みの符号反転で最短路にした場合、元の正閉路が負閉路になる。

距離の状態は少なくとも次を区別する。

- `INF`：到達不能
- 有限値：最短距離あり
- `-INF`：負閉路によりいくらでも小さくできる

## 5. 最短経路数・最短路グラフ

距離を求めた後、

$$
dist[u]+w(u,v)=dist[v]
$$

を満たす辺だけ残すと最短路グラフになる。

この等式は、その辺を使っても最短距離を超えないことを表す。逆に最短経路上の全辺は必ず等式を満たすため、元グラフから最短経路に関係しない辺を正確に除ける。

全辺重みが正なら距離が辺に沿って厳密に増えるので DAG。距離順に DP して経路数などを求められる。

`0` 重み辺があると同距離頂点間に閉路ができる可能性があり、単純な Dijkstra 同時 DP が正しいとは限らない。「経路」が walk か単純路かでも答えが変わる。

## 6. 差分制約（牛ゲー）

### 基本変換

$$
x_v-x_u\le c
\iff x_v\le x_u+c
$$

を最短路の緩和とみなし、辺を

```text
u -> v  (cost = c)
```

と張る。向きに迷ったら必ず $x_v\le x_u+c$ まで変形し、右辺の変数から左辺の変数へ張る。

| 元の制約 | `<=` 形 | 辺 |
|---|---|---|
| $x_v-x_u\le c$ | そのまま | `u -> v (c)` |
| $x_v-x_u\ge c$ | $x_u-x_v\le-c$ | `v -> u (-c)` |
| $x_v-x_u=c$ | 上の 2 制約 | `u -> v (c)`, `v -> u (-c)` |
| $x_v\le c$ | $x_v-x_S\le c$ | `S -> v (c)` |
| $x_v\ge c$ | $x_S-x_v\le-c$ | `v -> S (-c)` |

整数変数の厳密不等号は、$x<y\iff x-y\le-1$ のように非厳密不等号へ直す。

### 制約全体の充足可能性

変換後のグラフに負閉路があれば制約は矛盾、なければ実行可能解が存在する。

負閉路上の不等式を全て足すと、左辺の変数差が相殺して $0\le$「負の閉路長」となり矛盾する。逆に負閉路がなければ、超始点からの最短距離を各 $x_v$ に代入すると、全ての辺で $x_v\le x_u+c$ を満たす。

非連結部分を含む全グラフの負閉路を調べるには、超始点から全変数へ重み `0` の辺を張る。実装上は全頂点の初期距離を `0` にして Bellman–Ford を行ってもよい。

```cpp
vector<long long> dist(N, 0);
bool feasible = true;
for (int iter = 0; iter < N; ++iter) {
    bool updated = false;
    for (auto [u, v, w] : edges) {
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            updated = true;
            if (iter == N - 1) feasible = false;
        }
    }
    if (!updated) break;
}
```

負閉路がなければ、得られた `dist` 自体が全制約を満たす割り当ての一つ。

### 変数差の上界

`s` から `t` への経路上の制約を足すと、

$$
x_t-x_s\le\text{経路長}
$$

となる。したがって `dist[t]` は、制約から導ける $x_t-x_s$ の最も強い上界。

経路が複数あれば、その全てが上界を与える。上界として最も厳しいものは経路長の最小値なので、ここで最短路が現れる。「距離を最小化したいから」ではなく、「複数の上限制約のうち最小が有効だから」と捉えると辺の向きを判断しやすい。

- `t` が到達不能：有限上界を導けない。
- `s` から到達可能な負閉路：その部分の制約が矛盾。
- 有限距離：$x_t-x_s\le dist[t]$。

「制約全体の実行可能性」と「`s` から見た上界」は別の問い。必要なら超始点で全体を検査した後、`s` 始点でもう一度距離を求める。

### 牛ゲー型の辺

牛 `1..N` の座標を $x_1,\ldots,x_N$ とする。

距離が高々 `D`：

$$
x_B-x_A\le D
\quad\Longrightarrow\quad A\to B\ (D)
$$

距離が少なくとも `D`：

$$
x_B-x_A\ge D
\iff x_A-x_B\le-D
\quad\Longrightarrow\quad B\to A\ (-D)
$$

番号順に並ぶ：

$$
x_i\le x_{i+1}
\iff x_i-x_{i+1}\le0
\quad\Longrightarrow\quad i+1\to i\ (0)
$$

この制約は同じ座標を許す。整数座標で狭義に $x_i<x_{i+1}$ が必要なら $x_i-x_{i+1}\le-1$、すなわち `i+1 -> i (-1)` になる。問題文の「順番」と「異なる位置」を混同しない。

`1 -> N` の最短距離が、制約から導かれる $x_N-x_1$ の上界になる。

古典的な問題では「矛盾」「有限上界なし」「有限距離」に `-1`, `-2`, 距離などを割り当てる。具体的な出力値は問題文に従う。

一般の充足可能性では始点から到達不能な部分の負閉路も矛盾だが、特定始点から Bellman–Ford を行うだけでは検出できない。

### 最長路型

$$
x_v\ge x_u+c
$$

を `u -> v (c)` として `max` 緩和する書き方もあり、正閉路が矛盾を表す。ただし最短路型と混在させず、全制約を `<=` または `>=` のどちらかに統一する。

## 7. ポテンシャルと Johnson 法

ポテンシャル $h(v)$ で

$$
w'(u,v)=w(u,v)+h(u)-h(v)
$$

と変換する。全辺で $w'\ge0$ なら Dijkstra が使え、

$$
d'(s,t)=d(s,t)+h(s)-h(t)
$$

から元の距離へ戻せる。

Johnson 法は超始点から Bellman–Ford で $h$ を求め、各始点から Dijkstra を行う。負辺を含む疎グラフの全点対最短路向け。負閉路があれば使えない。

Bellman–Ford で得た $h$ は各辺について $h(v)\le h(u)+w(u,v)$ を満たすので、$w(u,v)+h(u)-h(v)\ge0$ が保証される。経路上では内部頂点のポテンシャルが相殺するため、経路の優劣は変わらない。

## 8. 落とし穴

- 差分制約の辺を逆に張る。式を $x_v\le x_u+c$ に直して確認する。
- Dijkstra に負辺を渡す。
- `INF + w` を計算する。
- 距離や和を `int` に入れる。
- 無向辺を片方向だけ追加する。
- Floyd–Warshall で対角 `0`、多重辺の `min`、到達可能性確認を忘れる。
- 負閉路の存在と、目的地がその影響を受けることを混同する。
- 全体の制約矛盾判定なのに超始点を使わない。
- 差分制約で「到達不能」を「解なし」と誤解する。上界がないだけの場合がある。
- `0` 重み辺がある最短経路数を、距離確定順だけで単純に数える。
- 状態に使用回数・向き・時刻など必要な情報を含め忘れる。
