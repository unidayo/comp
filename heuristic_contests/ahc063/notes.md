# AHC063 - Colorful Ouroboros

## 問題概要

N×N盤面（8≤N≤16）でヘビ（ウロボロス）を動かし、目標の色列にできるだけ近い最終状態を目指す。

## 初期状態

- ヘビの長さ: 5
- 全色: 1
- 位置（頭→尻尾）: (4,0), (3,0), (2,0), (1,0), (0,0)
- 盤面上に M-5 個の餌が散乱（色1~C）

## 1ターンの流れ（U/D/L/R を指示）

1. **移動**: 頭が指定方向へ1マス進む。尻尾が消える（長さ変わらず）
   - Uターン禁止、盤外禁止
2. **食事**: 移動先に餌があれば 長さ+1、餌の色が**尻尾の末端**に追加される
3. **噛みちぎり**: 移動後の頭が胴体インデックス h（1≤h≤k-2）に重なると、
   自動的に長さ h+1 になる。切れた尻尾側はそれぞれの色の餌として盤面に戻る

## スコア（最小化）

```
T + 10000 × (E + 2(M-k))
```

- T   : 操作回数（≤100,000）
- k   : 最終的なヘビの長さ
- E   : c[0..k-1] と d[0..k-1] の不一致数
- M-k : 食べ残した餌の数（2倍のペナルティ）

→ **餌を全部食べる（k=M）ことが最優先、次に色の一致**

## 入力形式

```
N M C
d_0 ... d_{M-1}        ← 目標色列（d_0=...=d_4=1）
f_{0,0} ... f_{0,N-1}  ← 各マスの餌の色（0=なし）
...
f_{N-1,0} ... f_{N-1,N-1}
```

## 出力形式

```
a_0     ← U/D/L/R
...
a_{T-1}
```

## 制約

- 8 ≤ N ≤ 16
- N²/4 ≤ M ≤ 3N²/4
- 3 ≤ C ≤ 7
- T ≤ 100,000
- 制限時間: 2秒（システムテストは余裕を持たせること）
- テストケース数: 暫定50個、システム2000個

## 重要な観察・考察

### 基本方針
- 全餌を食べる経路を作ることが最重要（M-k のペナルティが大きい）
- 蛇行（ジグザグ）で全マス巡回すれば全餌を食べられる
  → サンプルコードはこれをやっている
- ただし色列の一致は無視されるので E が大きくなりがち

### 色一致のために
- 餌を食べる順番が色列 c[5], c[6],... を決める
- 目標色列 d[5..M-1] に合わせた順番で餌を訪問したい
- 噛みちぎりを使えば色列を短くリセットできるが、操作数が増える

### 噛みちぎりについて
- 頭を自分の胴体マスへ移動したとき自動発動（制御不可）
- 切れた尻尾は餌として盤面に戻るため、再度食べられる
- 意図的に使うと「不要な色を捨てる」ことができる

### スコア分析
- ベースライン（蛇行で全餌食べる）: T ≈ N² 程度, E ≈ M-5 程度（ランダム）
  - 例: N=12, M=108, T≈144, E≈90 → 約 900,000 + 144
- 色一致最適化: E=0 にできれば 10000*(2*(M-k)) のみ → k=M なら 0
  - T は増えるがペナルティ削減で十分元が取れる
