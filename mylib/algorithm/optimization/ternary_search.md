# 三分探索（実数・整数）

閉区間内の単峰関数の最小値・最大値を探す。最小化では「狭義減少 → 最小値の区間 → 狭義増加」、最大化ではその逆が対象。最適位置が端点にある単調関数も扱える。最適値を取る区間は一点でも、平坦な区間でもよい。

区間の三等分点 `m1 < m2` を比較する。最小化で `f(m1) > f(m2)` なら最適位置は `m1` より右にあるので左側を捨てる。それ以外なら `m2` より右を捨てる。最大化では大小を逆にする。

## 実数版

`ternary_search_real.cpp` を貼り付けて使う。C++20 以上が必要。

```cpp
auto f = [](long double x) { return (x - 2) * (x - 2) + 3; };
auto [x, value] = ternary_search_real(-10.0L, 10.0L, f);
// x ≈ 2, value ≈ 3

auto g = [](double x) { return -(x - 4) * (x - 4); };
auto [argmax, maximum] = ternary_search_real<false>(0.0, 10.0, g, 100);
```

引数は `(left, right, f, iterations=200)`。端点は同じ浮動小数点型で渡す。返り値は `{探索中に評価した最良の位置, その関数値}`。両端点も評価するため、単調関数の端点最適解を拾える。同値の位置の選び方は保証しない。

一回で区間幅は約 `2/3` になる。初期幅 `W` を `eps` 以下にする反復回数の目安は `ceil(log(W/eps) / log(3/2))`。これは理想的な比較での区間幅の目安であり、関数値の誤差保証ではない。浮動小数点の丸めで区間を縮められなくなれば早期終了する。`f` の比較自体が丸めで同値になる場合にも精度は制限される。

## 整数版

`ternary_search_integer.cpp` を貼り付けて使う。

```cpp
auto f = [](long long x) { return (x - 7) * (x - 7); };
auto [x, value] = ternary_search_integer(-100, 100, f);
// x == 7, value == 0

auto g = [](long long x) { return -(x - 4) * (x - 4); };
auto [argmax, maximum] = ternary_search_integer<false>(0, 10, g);
```

引数は `(left, right, f)`。端点は `long long`、両端を含む。最後は最大4個の整数を全探索し、`{最も左の最適位置, その関数値}` を返す。区間幅の計算は `__int128` を使い、`LLONG_MIN` から `LLONG_MAX` の区間でも探索側の演算はオーバーフローしない。`f` 内の演算は呼び出し側で適切な型を使うこと。

## 適用条件と注意点

- 最適値以外の平坦区間を許す一般の弱単峰関数には、この同値処理を適用できない。例えば整数列 `[1, 1, 1, 1, 0]` では、三等分点がどちらも `1` になり、右端の最小値を捨てる可能性がある。
- 凸関数の最小化・凹関数の最大化は典型的な用途。複数の山や谷がある関数の大域最適解は保証しない。
- 同じ位置には同じ値を返す関数を渡す。NaN を返す関数は対象外。
- 整数上の離散凸関数なら、隣接差 `f(x+1)-f(x)` の符号を二分探索する方法も使える。三分探索が必要か、差分に単調性があるかを先に確認するとよい。

関数一回の評価時間を `T` とすると、実数版は `O(iterations * T)`、整数版は `O(log(right-left+1) * T)`。どちらも追加空間は `O(1)`。
