# IntervalSet

互いに重ならない半開区間 `[l, r)` を、左端の昇順で管理するデータ構造です。
区間の和集合だけを管理する使い方と、各区間に値を持たせて区間代入を行う使い方の両方に対応します。

## まず使う操作

```cpp
IntervalSet<long long> s;

s.insert(2, 5);           // {[2, 5)}
s.insert(5, 8);           // 隣接区間が結合されて {[2, 8)}
s.erase(4, 6);            // {[2, 4), [6, 8)}

bool a = s.contains(3);   // true: 3 を含む
bool b = s.contains(2, 4);// true: [2, 4) 全体を1本の区間が覆う
auto it = s.get(6);       // [6, 8) を指す。なければ s.end()
long long x = s.mex(2);   // 4: 2 以上で集合に含まれない最小値
```

全操作の区間は半開区間です。閉区間 `[L, R]` を扱いたい場合は、整数座標なら通常 `[L, R + 1)` に変換します。ただし `R` が型の最大値の場合は `R + 1` がオーバーフローするため、座標型や表現を変える必要があります。

## 値付き区間

`IntervalSet<T, VAL>` の `VAL` が区間の値です。`assign(l, r, value)` は `[l, r)` を指定値で上書きします。上書き後、隣り合う同値区間は自動的に結合されます。

```cpp
vector<int> a = {1, 1, 2, 2, 2, 1};
IntervalSet<int, int> s(a);
// ([0, 2): 1), ([2, 5): 2), ([5, 6): 1)

s.assign(1, 5, 3);
// ([0, 1): 1), ([1, 5): 3), ([5, 6): 1)

int v1 = s.value_at(3);   // 3
int v2 = s.value_at(10);  // identity（既定では int{}、つまり 0）
```

`insert(l, r)` は値として `identity` を使う `assign` です。値付き区間では、代入の意図が明確な `assign` の使用を勧めます。

## 検索と走査

- `get(p)`: `p` を含む区間。存在しなければ `end()`。
- `lower_bound(p)`: `p` を含む区間があればその区間、なければ `p` より右にある最初の区間。
- `contains(p)`: `p` がいずれかの区間に含まれるか。
- `contains(l, r)`: `[l, r)` が**1本の区間だけで**覆われるか。空区間は `true`。
- `same(p, q)`: `p`, `q` が同じ区間に含まれるか。
- `value_at(p)`: `p` を含む区間の値。区間外なら `identity`。
- `size()`: 保持している区間の本数。集合に含まれる整数点の個数や区間長の合計ではない。

範囲 `for` でも走査できます。

```cpp
for (const auto &[l, r, value] : s) {
    // [l, r) と value を使う
}
```

`Node` のメンバは `l`, `r`, `val` です。イテレータは内部の `std::set` の更新で無効になることがあるため、`insert`、`erase`、`assign` をまたいで保持しない方が安全です。

## add / del コールバック

外部で「値ごとの総区間長」などを管理するときは、更新される区間を通知するコールバックを渡せます。引数はどちらも `(l, r, value)` です。

```cpp
map<int, long long> length;
auto add = [&](int l, int r, int value) { length[value] += r - l; };
auto del = [&](int l, int r, int value) { length[value] -= r - l; };

s.assign(10, 20, 7, add, del);
s.erase(12, 15, add, del);
```

内部では、変更対象の既存区間をいったん丸ごと `del` し、残った断片を `add` し直します。そのため `add` と `del` は必ず互いに逆の操作にしてください。「実際に増減した部分だけが1回通知される」と仮定してはいけません。

また、コールバック付き操作を使う前に存在していた区間については、外部集計もあらかじめ同じ状態にしておく必要があります。コールバックなしの `clear()` は外部集計を更新しません。

## 計算量

保持区間数を `N`、1回の更新で削除・分割・結合される区間数を `k` とすると、検索は `O(log N)`、`insert` / `erase` / `assign` は `O((k + 1) log N)` です。`mex(p)` は `p` から隙間なく連なる区間を順にたどるため、調べた区間数を `k` として `O(log N + k)` です。
