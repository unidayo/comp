# AHC 上位解法サマリー

AHC001〜066 の問題文と、公式順位表上位10名の保存済み提出コードを照合した参照資料です。

- [コンテスト別まとめ](contest_summaries.md): 問題構造、上位解法の骨格、再利用ポイント
- [手法別索引](method_index.md): 新しい問題から類似過去問を逆引きするための索引
- 元コード: `../ahc001_049/`、`../ahc050_066/`

各項目は、10コードで共通する実装構造を中心にまとめています。細かな定数、近傍比率、温度、ビーム幅は入力分布と実行環境への依存が大きいため、利用時はリンク先の `metadata.json` と `submissions/` を確認してください。

## 使い方

1. 新しい問題の「状態」「操作」「目的関数」「不確実性」を分解する。
2. [手法別索引](method_index.md) から構造が近い問題を選ぶ。
3. [コンテスト別まとめ](contest_summaries.md) で状態・近傍・評価方法を確認する。
4. 元コードを開き、差分更新、時間配分、復元方法を現在の問題へ移植する。
